MathMusic phone hosting edition. See the chat hosting instructions.

Expanded MIDI search: BitMidi, FreeMidi and the Iranian MIDI Siavash catalog page are searched in parallel. Alternate Roman spellings Elaheh/Elaheye and doubled vowels are normalized. Use Other matches to select another arrangement. Paste a public HTTPS direct MIDI URL or a public catalog page containing a direct MIDI link to import from other websites. Links requiring login/payment, MP3 demos and PDF-only scores cannot be imported automatically. An unconfirmed artist warning means the song title matches but the file name does not confirm the requested artist. Preview before exporting. No search guarantees every song.

Song and artist suggestions: type 3 or more letters and pause briefly. Suggestions use Apple public music metadata; no preview audio is downloaded. Choosing a song fills both fields. Recent names are stored on this device. Typed text is sent to Apple for online suggestions; cached/recent results reduce requests. Suggestions do not guarantee MIDI availability.

Sheet music and appearance update: import partwise MusicXML (.xml/.musicxml) or compressed MXL. Score parts become the same timed graph notes as MIDI, with chords, rests, divisions, tempo changes, chromatic transposition, ties and multiple voices. PDF/photo notation recognition and native MSCZ import are not included. Export MusicXML/MIDI from MuseScore first. Grace notes are omitted; repeat endings and navigation signs require an unfolded export and produce a clear message instead of wrong timing. More source links include MuseScore, OpenSheets, Online Sequencer, and MIDI Find; these are discovery links, not additional automatic catalog crawlers. Settings provides light/dark/system themes, accent, text size and spacing, stored locally and excluded from video appearance. Uploaded scores are processed on the app server (your PC for Desktop; Render for hosted version), held in memory, not saved.
